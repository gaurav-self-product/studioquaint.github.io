STUDIO QUAINT - WEBSITE MANAGEMENT GUIDE (PHASE 1 MVP)
===================================================

This guide explains how to manage projects and team details on your new website.

1. HOW TO ADD A NEW PROJECT
---------------------------
Adding a project is fully automated. Simply follow these steps:

1. Create a new folder in: assets/projects/ (e.g., assets/projects/my-new-house/)
2. Add the following files into that folder:
   - info.json: A simple file with project details.
   - (Optional) panorama.jpg: A horizontal wide image for the main gallery.
   - (Optional) Images/: A folder containing project photos. If present, the website will automatically generate a beautiful grid photo gallery with an immersive fullscreen lightbox.
   - (Optional) 360: A folder containing 360-degree assets.

Example info.json:
{
  "title": "Amber Courtyard",
  "description": "A boutique hotel centered around a traditional Rajasthani courtyard.",
  "year": "2023",
  "location": "Jaipur",
  "has360": true
}

2. HOW TO ADD 360-DEGREE EXPERIENCES
------------------------------------
The website is designed to use exports from the Marzipano Tool (https://www.marzipano.net/tool/).

1. Upload your panorama to the Marzipano Tool.
2. Click "Export" to download a zip file.
3. Open the zip and find the folder containing 'app-files'.
4. Inside your project folder (e.g., assets/projects/stone-house/), create a folder named '360'.
5. Copy the contents of the Marzipano export into this '360' folder.
6. The folder structure MUST look like this:
   /assets/projects/stone-house/
     /info.json
     /panorama.jpg (Static preview)
     /360/
       /config.json (The scene logic)
       /tiles/ (The high-res image tiles)

3. HOW TO UPDATE TEAM MEMBERS
-----------------------------
For the MVP phase, team members are managed manually in 'team.html'.
1. Open 'team.html'.
2. Look for the "TEAM MEMBER CARD" sections.
3. Replace the placeholder names, roles, and bios inside the indicated tags.
4. Replace the 'src' link in the <img> tag with a real photo path.

4. UPDATING THE WEBSITE
-----------------------
Every time you add or update a project folder:

1. Run the local registry update script in your terminal:
   python3 .github/scripts/update_registry.py
   
   This script automatically scans all project subfolders, compiles their metadata, and catalogs any gallery images inside 'Images/' folders.
   
2. Commit and Push your changes to the Github repository.
